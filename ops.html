    🔑열쇠 (토큰)

    이 기기에 열쇠가 저장돼 있어요.

    폰 카메라로 찍으면 이 화면이 열리면서 열쇠가 저장돼요. 다 옮겼으면 꼭 닫으세요(QR 안에 열쇠가 들어 있어요).

    열쇠는 이 기기 안에만 저장돼요. 사이트나 게임 파일에는 들어가지 않아요.

    열쇠 만드는 법
    1. github.com 로그인 → 오른쪽 위 사진 → Settings
    2. 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
    3. 이름은 아무거나, 기간(Expiration)은 원하는 만큼
    4. Repository access → Only select repositories → cat-wizard-play 하나만
    5. Permissions → Repository permissions → Contents를 Read and write
    6. Generate token → 나온 글자를 복사해 위에 붙여 넣기
